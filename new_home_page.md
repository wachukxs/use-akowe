AKOWE Landing Page Improvements Doc
The Biggest UX Problem
The landing page currently requires too much reading, interpretation, and too much cognitive effort upfront.
Key Improvements to Make the Interface Simpler
1. Simplify the Hero Section 
Headline: Generate research topics, literature reviews, citations, plagiarism checks, and supervisor-ready drafts in one workspace.
CTA Button: Start Your Thesis Free
2. Reduce Text Density Across the Entire Site
Current issue:
Large blocks of text make the experience feel:academic, heavy, and mentally demanding. Students skim, especially mobile users from Instagram ads.
The solution is to use shorter sentences, more spacing, more icons, more visual hierarchy, more screenshots, Users should see dashboard screenshots, plagiarism scans, topic generation, literature synthesis, within the first scroll. It would help if we are able to get short thesis sample to put in the homepage, almost similar to jenni.ai 
So the section with the screenshots should come before the “How it Works” section.
3. Add “Choose What You Need Help With”. Instead of forcing users to understand Akowe as a full ecosystem immediately. We can add a section to know what they need help with to reduce the overwhelming structure.
Buttons:
Finding a research topic
Writing literature review
Checking plagiarism
Citations & references
Methodology chapter
Thesis structure
Supervisor revisions
Sections to Remove:
Most AI tools put your grade at risk.
Akowe is built for academic integrity
Designed for academic submission (there are 2 of this section on the dashboard, we can retain the one with the checkmark)
4. Mobile Optimization Should Have Less Block Letters. The texts should feel light, fast, softer on the eyes so that it does not appear overstimulating to the user.
